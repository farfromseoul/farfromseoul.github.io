  • Google: Gmail·Drive·Docs 등 Workspace용 MCP 서버와 공식 CLI를 정식 출시(GA) 했습니다. 그리고 2027년 2월 1일부터 AI 에이전트는 Workspace REST API를 직접 부르지 말고 MCP를 거치도록 기술적으로 강제합니다. API 사용량 등급(Standard·Scaled)도 새로 정했습니다.
  • Anthropic: Claude가 만든 아티팩트(대화 속에서 만든 작은 웹 페이지·도구)를 Mac·Windows 데스크톱 앱으로 설치하는 “Install as app” 베타를 열었습니다. 권한을 주면 앱이 파일을 읽고 프로그램을 실행할 수도 있습니다.

두 소식 모두 새 모델이나 벤치마크 발표가 아니라 AI 에이전트의 접근 경로와 권한에 관한 변화입니다. 그래서 이 글에는 성능 수치가 없고, 숫자는 회사가 밝힌 값과 날짜만 다룹니다(2026-11-27 확인 기준).

먼저 용어 몇 가지

  • MCP(Model Context Protocol): AI 앱이 외부 서비스의 도구와 데이터를 쓰도록 이어 주는 공개 표준입니다. “AI용 USB 포트"처럼 서비스마다 따로 연동하지 않아도 되게 해 줍니다.
  • REST API: 프로그램이 HTTP 요청으로 서비스 기능을 부르는 일반적인 방식입니다. 지금까지 Workspace 연동 대부분이 이 방식이었습니다.
  • AI 에이전트: 사람이 한 단계씩 지시하지 않아도 모델이 스스로 도구를 골라 여러 단계 작업을 하는 프로그램입니다.
  • OAuth 클라이언트: 앱이 사용자 대신 Google 계정 데이터에 접근하도록 허락받을 때 쓰는 앱 등록 정보입니다.
  • 아티팩트(Artifact): Claude 대화에서 만들어지는 HTML 페이지·작은 도구 같은 결과물입니다.

한계·주의할 점

  • Workspace 연동을 만든 팀: 직접 만든 AI 에이전트가 Gmail·Drive를 REST API로 부르고 있다면 2027년 2월 1일 전에 MCP로 옮길 계획이 필요합니다. 반대로 사람이 쓰는 일반 앱이라면 지금 당장 바꿀 이유는 확인되지 않습니다.
  • 판단 기준이 아직 흐림: “무엇이 에이전트인가"를 가리는 기준이 OAuth 표시 외에는 자세히 공개되지 않았습니다. 모델이 일부 단계에만 끼어 있는 자동화가 어디에 속하는지는 Google 안내를 더 지켜봐야 합니다.
  • Scaled 요금 정보는 엇갈림: MCP 사용에도 무료 허용량이 있는지, 단가가 얼마인지 보도마다 다릅니다. 예산을 잡기 전 공식 등급 페이지를 확인하세요.
  • CLI 설치 경로: 설치는 Google 공식 안내 문서에 나온 경로로만 하세요. 이 글에는 검증하지 못한 설치 명령을 넣지 않았습니다.
  • Claude 앱의 전체 접근: 파일 삭제와 프로그램 실행까지 맡기는 권한입니다. 무엇을 하는지 모르는 앱, 남이 공유한 앱에는 주지 않는 편이 안전합니다.
  • 회사 PC: Enterprise는 관리자가 켜야 쓸 수 있지만 Team은 기본으로 켜져 있습니다. 회사 보안 담당자는 조직 설정을 미리 확인하는 것이 좋습니다.
  • 두 소식 모두 발표 직후 정보입니다. 베타·순차 배포 단계라 세부 사항이 바뀔 수 있습니다.

나에게 맞는 선택

  • 입문자·학생: Claude로 만든 타이머, 메모장 같은 작은 도구를 앱처럼 띄워 보는 데는 “기본” 권한이면 충분합니다. 전체 접근은 무엇을 하는 앱인지 이해한 뒤에만 켜세요.
  • Workspace를 쓰는 직장인: 회사 관리자가 AI 도구 접근을 새 제어 화면에서 정리할 가능성이 큽니다. 쓰던 AI 연동이 갑자기 확인 창을 띄우거나 막히면 이 변화 때문일 수 있습니다.
  • 개발자: 내 프로젝트의 OAuth 클라이언트 중 AI 모델이 움직이는 것이 있는지 목록부터 만들어 두세요. MCP 서버로 옮기면 관리자 확인 규칙·감사 로그를 그대로 쓸 수 있다는 장점이 있습니다.
  • 보안·IT 관리자: Workspace의 API 제어와 Claude 조직 설정의 아티팩트 앱 항목을 둘 다 점검 목록에 올리세요.

정리

  • Google은 Workspace MCP 서버 8종과 공식 CLI를 정식 출시하고, 2027년 2월 1일부터 AI 에이전트는 MCP로만 Workspace 데이터에 접근하도록 제한합니다. REST API 자체가 없어지는 것은 아닙니다.
  • Scaled 등급 과금은 2027년 4월 1일부터이고, Google은 99% 이상의 개발자가 무료 Standard 안에 있다고 밝혔습니다(회사 집계).
  • Anthropic은 Claude 아티팩트를 Mac·Windows 앱으로 설치하는 베타를 열었습니다. 편해진 만큼 “전체 컴퓨터 접근” 권한은 신중하게 줘야 합니다.
  • 두 발표 모두 AI 에이전트의 접근 통로를 정해진 길로 모으고, 그 길에 확인·권한 장치를 붙이는 방향입니다.
