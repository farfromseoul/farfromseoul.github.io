  • 앱에서 쓰던 웹 검색, 생각하며 검색하기, 파일 읽기, 링크 읽기, 안전 검사를 API 요청에 파라미터 몇 개만 넣어 켤 수 있습니다. 검색·결과 정리는 DeepSeek 서버가 처리합니다.
  • 검색(Search)·페이지 가져오기(Fetch)·문자 인식(OCR)·음성 인식(ASR)·음성 합성(TTS)은 따로 부르는 API로도 나왔습니다.
  • 대상 모델은 V4.1-Flash(deepseek-flash) 하나입니다.
  • 도구를 쓰면 토큰 요금에 도구 요금이 더해집니다. 그리고 도구를 켜면 temperature 같은 일부 설정이 조용히 무시됩니다.
  • 일반 사용자에게 공개하는 앱은 안전 검사를 반드시 켜야 합니다.

먼저 밝혀 둡니다. 이 초안은 Anthropic의 AI 모델(Claude Opus 5.5)이 작성했습니다. 경쟁사 소식인 만큼 DeepSeek 공식 문서(①)에 있는 내용만 사실로 적고, 보도(②)는 교차 확인용으로만 썼습니다. 이번 발표는 기능·가격 발표라 성능(벤치마크) 수치는 없습니다.

먼저 용어 몇 가지

  • 내장 도구(built-in tool): 개발자가 직접 검색 코드를 짜지 않아도, API 요청에 “검색 써도 돼"라고 표시만 하면 모델 제공사 서버가 검색하고 결과를 대화에 붙여 주는 기능.
  • 생각 모드(thinking): 모델이 답하기 전에 여러 단계로 추론하는 설정. DeepSeek은 이 모드에서 검색을 켜면 “생각하며 검색하기(Deep Thinking Search)“로 동작합니다.
  • 엔드포인트: API 요청을 보내는 주소. DeepSeek은 OpenAI 방식(Chat Completions, Responses)과 Anthropic 방식(Messages) 주소를 모두 제공합니다.
  • OCR / ASR / TTS: 이미지 속 글자 읽기 / 음성을 글로 바꾸기 / 글을 음성으로 바꾸기.
  • QPS: 초당 요청 수 한도.

계산해 보면 검색 한 번은 $0.00075(약 1원)입니다. 싸 보이지만, 생각하며 검색 모드는 한 번의 질문에 검색·페이지 읽기를 여러 번 할 수 있으므로 질문당 비용은 호출 횟수만큼 불어납니다. 할인 종료일은 공지에 없습니다.

한계·주의할 점

  • 도구를 켜면 일부 설정이 무시됩니다. 검색·링크 읽기를 선언하거나, 안전 검사를 high로 두거나, 제목 생성을 켜면 temperature, top_p, 정지 문자열(stop), seed 같은 값이 적용되지 않습니다(엔드포인트마다 목록이 다름). 답변을 일정하게 만들려고 이 값에 기대던 코드라면 결과가 달라질 수 있습니다.
  • 출력 토큰 한도의 뜻이 바뀝니다. max_tokens가 한 번의 응답 전체가 아니라 추론 단계마다 적용됩니다. 비용 상한으로 쓰고 있었다면 실제 출력은 그보다 커질 수 있습니다.
  • 모델이 하나뿐입니다. 내장 도구는 V4.1-Flash 기준으로만 안내돼 있고, 상위 모델(deepseek-v4-pro)에서 되는지는 공지에 없습니다. 또 웹 검색 단독 모드는 생각 모드가 꺼진 상태로 동작합니다.
  • 안전 검사는 “기본 장치"일 뿐입니다. 공식 공지는 공개 서비스라면 안전 검사를 켜야 하고, 콘텐츠 검수·AI 생성물 표시·관련 등록 의무는 개발자 책임이라고 밝힙니다.
  • 데이터가 어디로 가는지 확인하세요. 검색어, 읽게 한 URL, 올린 파일은 모두 DeepSeek 서버에서 처리됩니다. 회사 문서나 개인 정보를 넣기 전에 소속 조직의 외부 AI 사용 정책과 DeepSeek 이용 약관을 먼저 확인하는 것이 안전합니다.
  • 속도 한도: 단독 Search·Fetch API는 계정당 각각 5 QPS라는 보도(②)가 있지만, 이번 공지에는 내장 도구의 한도가 적혀 있지 않습니다.

나에게 맞는 선택

이런 분이라면이렇게
처음 AI API를 써 보는 학생·취준생검색 붙은 챗봇을 직접 만들어 보기 좋은 재료입니다. 채팅 데모를 먼저 살펴보고, 결제 한도를 낮게 걸어 두고 시작하세요.
이미 직접 검색 API를 붙여 쓰는 개발자서버 쪽 코드가 줄어드는 대신 검색 품질·호출 횟수를 직접 통제하기 어려워집니다. 같은 질문 몇십 개로 비용과 결과를 비교해 보고 옮기세요.
temperature·seed로 출력을 고정하던 서비스도구를 켜면 이 값이 무시되므로, 회귀 테스트를 다시 돌려 보세요.
회사 서비스에 붙이려는 팀안전 검사 의무, 데이터 처리 위치, 사내 보안 정책부터 확인하세요.

다른 회사들도 서버 쪽 검색 도구를 제공하므로, “검색 붙은 모델"을 고를 때는 토큰 단가만이 아니라 질문당 검색 횟수 × 도구 요금까지 합쳐서 비교하는 것이 맞습니다.

정리

DeepSeek은 앱의 검색·파일·링크·안전·음성 기능을 API로 열어, 개발자가 직접 붙여야 했던 부분을 서버 쪽으로 가져갔습니다. 도구 요금은 건당 아주 작지만 생각하며 검색처럼 여러 번 부르는 모드에서는 쌓이고, 도구를 켜는 순간 일부 생성 설정이 무시되며 출력 한도의 의미도 바뀝니다. 붙이기 전에 비용 상한, 출력 일관성, 데이터 처리 정책 세 가지를 확인하세요.
