2026년 11월 10일(미국 시간), Anthropic이 Claude 안에서 쓰는 업무 도구 네 가지를 한 번에 발표했습니다. 핵심만 먼저 정리하면 이렇습니다.

  • Claude Sheets(베타): Claude가 탭·수식·서식·드롭다운이 있는 스프레드시트를 만들고 함께 고칩니다.
  • Claude Whiteboards(베타): 회의·브레인스토밍 내용을 일정표와 할 일로 정리해 주는 공유 보드입니다.
  • Claude Meetings(베타): Claude가 화상 회의에 참석자로 들어가 회의 중에 계획과 할 일을 정리합니다. 우선 Google Meet, Team·Enterprise 요금제만.
  • Claude Data(정식 출시): 10월에 베타로 나온 Claude Dashboards의 새 이름. 데이터 웨어하우스·CRM에 연결해 대시보드와 데이터 설명 글을 만듭니다.

먼저 밝혀 둡니다. 이 초안은 Anthropic의 AI 모델(Claude Opus 5.5)이 작성했고, 다루는 것도 Anthropic 제품입니다. 그래서 공식 발표와 외부 보도 두 곳 이상에서 확인한 내용만 실었고, 한계와 주의할 점도 같은 비중으로 적었습니다.

무슨 일이 있었나

지금까지 Claude는 “대화하고 답을 받는 곳"에 가까웠습니다. 이번 발표는 그 결과물을 문서·표·보드처럼 계속 열어 두고 고치는 작업물로 만들겠다는 방향입니다. 해외 매체들은 이를 Microsoft·Google 오피스 도구와 겨루는 움직임으로 봤습니다.

먼저 용어 몇 가지

  • 베타(beta): 기능을 먼저 열어 두고 피드백을 받는 단계. 동작이 바뀌거나 빠진 기능이 있을 수 있습니다.
  • 에이전트(agent): 질문에 답만 하는 게 아니라, 도구를 써서 여러 단계의 일을 스스로 이어서 하는 AI.
  • 커넥터(connector): Claude가 외부 서비스(Notion, Box, 데이터베이스 등)에 접근하도록 이어 주는 연결. 이번 발표의 커넥터는 MCP(Model Context Protocol, AI와 외부 도구를 잇는 공개 규약) 기반입니다.
  • 데이터 웨어하우스(data warehouse): 회사의 분석용 데이터를 한곳에 모아 두는 저장소. BigQuery, Amazon Redshift, ClickHouse 같은 것들입니다.
  • 인증된 쿼리(certified query): 관리자가 “이 지표는 이 계산식이 맞다"고 확인해 둔 질의. 사람마다 다른 방식으로 매출을 계산하는 문제를 막으려는 장치입니다.

3. 성능 수치는?

이번 발표는 새 모델이 아니라 제품 기능 발표라서 벤치마크 같은 성능 수치는 공개되지 않았습니다. 독립 평가도 아직 없습니다(2026-11-12 확인 기준). “얼마나 정확하게 표를 만드는지"는 직접 써 보며 판단해야 합니다.

한계와 주의할 점

1. Sheets는 아직 “가벼운 표” 수준입니다. Anthropic 스스로 지금은 단순한 기능만 있고 더 추가할 예정이라고 밝혔습니다. 복잡한 재무 모델이나 큰 데이터 처리가 필요하면 .xlsx로 내보내 엑셀에서 마무리하라는 안내입니다. 베타인 만큼 수식 결과는 꼭 한 번 직접 검산하세요.

2. 회의 에이전트는 개인정보·동의 문제가 따라옵니다. Claude Meetings는 스스로 참석자임을 밝히고 회의 채팅에 안내를 남깁니다. 외부 손님이 있는 회의에는 관리자가 허용하지 않으면 들어가지 않고, 회의 중 외부 손님이 들어오면 자동으로 나갑니다. 장치는 있지만, 회의 내용이 어디에 얼마나 보관되는지는 보도 기준으로 자세히 나오지 않았습니다. 회사에서 쓰려면 사내 보안 규정과 참석자 동의를 먼저 확인하세요.

3. Data는 “누가 어떤 데이터를 볼 수 있나"를 먼저 정해야 합니다. 실시간 공유를 쓰면 동료가 커넥터 권한 없이도 대시보드 숫자를 봅니다. 다만 보는 사람은 소유자가 승인한 쿼리만 실행할 수 있고, 소유자 권한으로 다른 쿼리를 돌릴 수는 없습니다. 실시간 공유와 인증된 쿼리는 아직 베타입니다. Enterprise는 11월 19일에 Data가 기본으로 켜지므로, 관리자라면 그 전에 설정을 확인해 두는 게 좋습니다.

4. Claude 안에 일이 몰리는 구조입니다. 편리한 만큼, 회사 문서와 데이터가 한 AI 서비스에 모입니다. 내보내기(.xlsx·CSV, 문서 변환)가 되는지, 기존 도구와 어떻게 나눠 쓸지 미리 정해 두면 나중에 옮길 때 덜 고생합니다.
