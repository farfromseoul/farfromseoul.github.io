GPT-Live-1.1 API 공개: 음성 에이전트의 '말 없는 시간' 요금이 분당 0.05달러에서 0.02달러로

ChatGPT 음성 모드에 쓰이던 GPT-Live-1.1이 OpenAI API로 나왔고, 대화가 멈춘 동안 싼 요금이 붙는 Standby 모드가 생겼습니다. 바뀐 점과 요금 계산법, 아직 확인되지 않은 부분을 나눠 정리합니다.

2026-11-21 · #llm #ai-model #openai #voice-ai #realtime #api-pricing

  • 요금은 얼마나 달라지나

2026년 11월 20일(UTC), OpenAI 개발자 포럼에 GPT-Live-1.1이 API에 들어왔다는 공지가 올라왔습니다. 지난 10월 15일부터 ChatGPT Plus·Pro의 음성 대화를 맡아 온 모델을 이제 개발자도 자기 서비스에 붙일 수 있게 된 것입니다. 함께 나온 Standby(대기) 모드는 대화가 멈춘 동안의 요금을 낮춰 줍니다. 핵심만 먼저 정리합니다.

  • 모델 ID는 gpt-live-1.1. 말하는 동안에도 듣는 전이중(full-duplex) 음성 모델이고, 복잡한 일은 개발자가 고른 백엔드 모델에 넘깁니다.
  • 요금은 대화 중 분당 0.05달러, Standby 중 분당 0.02달러. 백엔드 모델·도구 사용료는 따로 붙습니다.
  • Standby는 기존 GPT-Live-1에서도 켤 수 있습니다.
  • 성능 수치(벤치마크)는 회사 발표에도, 독립 평가에도 아직 없습니다(2026-11-21 확인 기준).

먼저 밝혀 둡니다. 이 초안은 OpenAI의 경쟁사인 Anthropic의 AI 모델(Claude Opus 5.5)이 작성했습니다. 그래서 OpenAI 공식 공지에 나온 내용과, 서로 다른 매체 두 곳 이상에서 같게 확인된 내용만 실었습니다. 한 곳에만 나온 세부 제한값(지시문 토큰 수, 지원 전송 방식 일부, 과금 단위 등)은 뺐습니다. OpenAI 공식 문서 페이지는 이번 작성 환경에서 열리지 않아, 포럼 공지와 기술 매체 보도로 교차 확인했습니다.

먼저 용어 몇 가지

  • 음성 에이전트: 사람과 말로 주고받으며 예약·상담·안내 같은 일을 처리하는 AI 프로그램.
  • 전이중(full-duplex): 전화처럼 양쪽이 동시에 말하고 들을 수 있는 방식. 사용자가 중간에 끼어들어도 바로 알아챕니다. 반대는 무전기처럼 한쪽씩 말하는 반이중입니다.
  • 백엔드 모델: 음성 모델 뒤에서 검색·추론·함수 호출 같은 무거운 일을 맡는 별도 모델. 음성 모델은 “말하기·듣기”, 백엔드 모델은 “생각하기"를 나눠 맡는 구조입니다.
  • WebRTC: 브라우저·앱에서 음성·영상을 실시간으로 주고받는 표준 기술. 화상회의 서비스가 흔히 씁니다.
  • 유휴 시간(idle time): 연결은 열려 있지만 아무도 말하지 않는 시간.

Standby 모드는 이렇게 동작합니다

  1. 개발자가 유휴 제한 시간을 5~60초 사이로 정합니다.
  2. 그 시간 동안 아무도 말하지 않으면 모델이 잠시 멈춥니다. 이때 WebRTC 통화 연결은 끊기지 않고 그대로 열려 있습니다.
  3. 누군가 다시 말하면 대화가 이어집니다.

전화를 끊고 다시 거는 게 아니라, 통화는 유지한 채 “대기"만 하는 셈입니다. 손님이 메뉴를 고민하는 동안, 학생이 문제를 푸는 동안처럼 말 없는 시간이 긴 서비스일수록 효과가 큽니다.

유휴 시간만 놓고 보면 분당 요금이 60% 줄어듭니다. 다만 Standby는 정한 제한 시간이 지난 뒤에 들어가므로, 제한 시간을 60초로 길게 잡으면 짧은 침묵은 그대로 대화 요금으로 계산됩니다. 실제 절감 폭은 서비스의 대화 패턴과 제한 시간 설정에 따라 달라집니다.

“더 자연스럽다”, “더 안정적이다"는 회사가 스스로 한 평가입니다. 한국어 억양·숫자 읽기(전화번호, 금액)처럼 내 서비스에 중요한 부분은 직접 시험해 보는 수밖에 없습니다.

한계·주의할 점

  • 기존 Realtime API에서 모델 이름만 바꿔서는 안 됩니다. 두 매체 모두 세션을 만드는 경로와 연결 방식이 달라 코드 수정이 필요하다고 전합니다. 이전 계획은 공식 문서를 먼저 확인하세요.
  • 총비용은 음성 요금보다 클 수 있습니다. 백엔드 모델이 추론·검색·함수 호출을 할 때마다 그 모델의 토큰 요금이 따로 붙습니다. 분당 0.02달러만 보고 예산을 잡으면 틀립니다.
  • Standby는 WebRTC 연결을 전제로 설명돼 있습니다. 다른 연결 방식에서 어떻게 동작하는지는 이번에 공식 문서로 확인하지 못했습니다.
  • 요금제 등급별 사용 한도, 제공 지역은 확인한 자료에 나오지 않았습니다.
  • 음성 비서는 녹음·개인정보 처리 문제가 따라옵니다. 사용자에게 녹음·AI 사용 사실을 알리는 안내는 서비스 쪽 책임입니다.

나에게 맞는 선택

입문자·학생이라면

  • 당장 바뀌는 건 없습니다. ChatGPT 앱의 음성 대화가 이미 이 모델로 돌아가고 있으니, 써 보면서 “말하는 도중 끼어들기"가 어떻게 처리되는지 느껴 보면 됩니다.
  • 음성 앱을 만들어 보고 싶다면 “음성 모델 + 백엔드 모델” 두 단으로 나누는 구조를 이해해 두면 다른 회사 음성 API를 볼 때도 도움이 됩니다.

개발자라면

  • 이미 GPT-Live-1을 쓰고 있다면, 모델을 바꾸지 않고도 Standby만 먼저 켜서 비용 변화를 볼 수 있습니다.
  • Realtime API 기반 서비스라면 경로·연결 방식이 달라지므로, 작은 기능 하나로 시범 이전해 보고 지연 시간·비용을 비교하세요.
  • 비용 추정은 “대화 분 + 대기 분 + 백엔드 토큰” 세 덩어리로 나눠 잡고, 실제 로그로 유휴 비율을 먼저 재 보는 게 좋습니다.

정리

GPT-Live-1.1의 API 공개는 성능 경쟁보다 음성 에이전트의 운영 비용 구조를 바꾸는 소식에 가깝습니다. 말 없는 시간이 긴 상담·학습·안내 서비스라면 Standby로 음성 요금을 꽤 줄일 수 있습니다. 다만 성능 수치는 아직 회사의 설명뿐이고, 백엔드 모델 비용과 Realtime API에서의 이전 작업은 따로 따져 봐야 합니다.
