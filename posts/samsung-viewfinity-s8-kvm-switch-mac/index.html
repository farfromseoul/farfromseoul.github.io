삼성 뷰피니티 S8(S80UD) 모니터의 내장 KVM으로 Mac mini M4와 Mac Studio M1 Max를 키보드·마우스 한 벌로 오가는 방법입니다. 케이블 연결, OSD 설정, PBP·PIP 차이, 블루투스가 전환되지 않는 이유, 외장 SSD 주의점까지 그림과 시뮬레이터로 정리했습니다.

책상 위에 Mac이 두 대 있으면 키보드와 마우스도 두 벌이 되기 쉽습니다. 삼성 뷰피니티 S8 S80UD는 모니터 안에 KVM 스위치가 들어 있어서, 키보드·마우스 한 벌로 두 컴퓨터를 번갈아 쓸 수 있습니다. 이 글은 32인치 S80UD에 Mac mini M4와 Mac Studio M1 Max를 연결한 구성을 기준으로 정리했습니다.

사양과 메뉴 이름은 삼성 공식 제품 페이지·데이터시트와 S80UD가 포함된 삼성 사용 설명서(S60D·S60UD·S70D·S80D·S80UD 공용)를 기준으로 확인했습니다. 메뉴 이름과 동작은 펌웨어·판매 지역에 따라 다를 수 있으니, 내 모니터의 설명서를 함께 확인해 주세요. (2026-11-21 확인)

KVM 스위치란?

KVM은 Keyboard(키보드), Video(화면), Mouse(마우스)의 앞 글자입니다. 모니터·키보드·마우스 한 벌로 여러 대의 컴퓨터를 번갈아 조작하게 해 주는 장치를 KVM 스위치라고 부릅니다.

원래는 책상 위에 따로 두는 상자였는데, 뷰피니티 S8 S80UD는 이 기능을 모니터 안에 넣었습니다. 삼성은 제품 페이지에서 내장 KVM으로 두 대의 기기를 키보드·마우스 한 벌로 연결하고 제어할 수 있다고 설명합니다. 그래서 별도의 외장 KVM 스위치 없이 두 컴퓨터를 오갈 수 있습니다.

핵심 원리는 간단합니다. 모니터 뒤의 USB 허브(키보드·마우스를 꽂는 USB-A 포트들)가 지금 보고 있는 컴퓨터 쪽으로 통째로 연결이 바뀌는 것입니다.

KVM 연결 아키텍처

장비모니터 연결 포트용도
Mac mini M4USB-C영상 + USB 데이터 (케이블 하나)
Mac Studio M1 MaxHDMI 또는 DisplayPort영상 및 음성 전송
Mac Studio M1 MaxUSB Type-B 업스트림USB 데이터 전송

삼성 S80UD 데이터시트(37형 기준)를 보면 영상 입력이 HDMI · DisplayPort · USB-C(최대 90W 충전) 세 가지 있고, USB-B 업스트림 1개, USB 3.0 다운스트림 3개, LAN 포트 1개가 있습니다. 32형도 같은 계열 구성으로 소개되지만, 구매 전 내 모델의 사양표를 한 번 더 확인하세요. 설명서에는 다운스트림 포트가 USB-C 케이블로 PC를 연결했을 때, 그리고 USB Type-B 케이블로 PC를 연결했을 때 활성화된다고 적혀 있습니다. 컴퓨터마다 USB가 들어오는 길이 하나씩 있어야 KVM이 동작하는 이유입니다.

KVM 연결 및 설정 방법

STEP 1. 컴퓨터 두 대 연결

  • 첫 번째 Mac(Mac mini M4): 모니터의 USB-C 포트에 연결합니다. 케이블 하나로 영상과 USB 데이터가 함께 갑니다.
  • 두 번째 Mac(Mac Studio M1 Max): HDMI 또는 DisplayPort로 영상을 연결합니다.
  • 두 번째 Mac과 모니터의 USB-B 업스트림 포트를 USB 케이블로 한 번 더 연결합니다. Mac Studio M1 Max는 뒷면에 USB-A 단자가 있어서 USB-A to USB-B 케이블을 쓰면 됩니다.
  • MacBook처럼 USB-A 단자가 없는 장비는 USB-C to USB-B 케이블이나 USB-C 변환 어댑터를 씁니다.

USB-B 케이블은 구성품에 없을 수 있습니다. 국내 37형 S80UD 리뷰에서도 USB 허브에 필요한 Type-B 케이블은 별도 구매로 소개됐습니다. 구성품은 모델·지역마다 다르니 상자를 먼저 확인하세요.

STEP 2. 키보드와 마우스 연결

  • 키보드와 마우스를 모니터의 USB-A 다운스트림 포트에 꽂습니다.
  • 무선 장치라면 Logi Bolt나 Unifying 같은 USB 수신기를 모니터 포트에 꽂습니다.
  • Mac에 블루투스로 직접 페어링한 장치는 KVM 전환을 따라가지 않습니다. 블루투스 연결은 모니터 허브를 거치지 않고 Mac과 장치가 직접 맺은 연결이기 때문입니다. (아래 Bluetooth와 Logi Bolt의 차이 참고)

STEP 3. 모니터 설정

  1. 모니터 뒤 조작 버튼으로 OSD 메뉴에 들어갑니다.
  2. Source 메뉴에서 볼 영상 입력을 고릅니다.
  3. System 메뉴의 USB Source Setup을 확인합니다. 설명서는 이 항목을 “영상 입력에 할당할 USB 포트를 설정"하는 메뉴라고 설명합니다.
    • USB-C 영상 입력 → USB 소스도 USB-C
    • HDMI 또는 DP 영상 입력 → USB 소스는 USB-B
  4. 이렇게 짝을 지어 두면 영상 입력을 바꿀 때 키보드·마우스도 같은 컴퓨터로 넘어갑니다.

영상 입력과 USB 소스가 어떤 방식으로 함께 바뀌는지, 세부 선택지 이름은 모델과 펌웨어에 따라 다를 수 있습니다. 설명서에는 USB-C 입력 모델(S80UD 포함)에서 조작 버튼을 오른쪽으로 누르면 USB 소스 전환, 왼쪽으로 누르면 입력 소스 조정이라는 바로가기 안내도 있습니다. 새 입력이 연결되면 자동으로 화면을 바꿔 주는 Auto Source Switch+ 기능도 있어서, 원하지 않는 전환이 일어나면 이 설정을 확인해 보세요.

인터랙티브 KVM 시뮬레이터

아래 버튼을 눌러 보세요. 화면, 연결선, 키보드·마우스가 어느 컴퓨터를 조작하는지가 함께 바뀝니다. 활성 연결은 색이 있는 흐르는 선, 비활성 연결은 회색 점선입니다.

KVM 시뮬레이터$ kvm --switch

실제 모니터를 제어하지 않아요. KVM이 어떻게 동작하는지 눈으로 보는 연습용 화면이에요.

Active Device

USB 소스
USB-C (영상과 같은 케이블)

Mac mini를 고르면 초록색 USB-C 한 줄이 영상과 키보드·마우스를 모두 담당합니다. Mac Studio를 고르면 파란 HDMI/DP(영상)와 주황 USB-B(키보드·마우스) 두 줄이 함께 켜집니다. 같은 일을 하는데 Mac Studio 쪽만 케이블이 두 개 필요한 이유가 여기서 보입니다.

KVM vs PBP vs PIP

이름이 비슷해서 헷갈리지만 하는 일이 다릅니다.

기능영문명설명
KVMKeyboard, Video, Mouse컴퓨터의 영상 및 입력 장치 제어 대상 전환
PBPPicture by Picture두 컴퓨터의 화면을 좌우로 분할하여 출력
PIPPicture in Picture메인 화면 내부에 다른 컴퓨터의 화면을 작게 출력

S80UD의 삼성 공식 사양에는 PIP와 PBP가 모두 지원으로 나와 있습니다. 버튼으로 세 가지 모드를 비교해 보세요.

화면 모드 미리보기$ display --mode

A · Mac mini M4USB-C
B · Mac StudioHDMI/DP

한 화면: 선택한 입력 하나만 화면 전체에 보여요.

두 화면을 동시에 띄워도 키보드·마우스는 한 번에 한 컴퓨터만 조작합니다. 설명서에는 PIP/PBP 메뉴 안에 Switch USB(PIP/PBP 모드에서 USB 소스 전환) 항목이 따로 있습니다. 또 PIP/PBP를 켜면 일부 화질·눈 보호 메뉴를 쓸 수 없고, 맞지 않는 해상도에서는 화면이 비정상적으로 보이거나 꺼질 수 있다고 안내합니다.

Bluetooth와 Logi Bolt의 차이

KVM이 전환해 주는 것은 모니터 USB 허브에 꽂힌 장치뿐입니다.

연결 방식KVM 전환 연동
USB 유선 장치가능
Logi Bolt 수신기가능
Unifying 수신기가능
Mac 직접 Bluetooth 연결불가능

MX Master 4처럼 Logi Bolt를 지원하는 마우스는 호환 수신기를 모니터 USB 허브에 꽂으면 KVM과 함께 쓸 수 있습니다.

몇 가지 주의할 점이 있습니다.

  • Logi Bolt와 Unifying은 서로 다른 규격입니다. MX Master 4는 Logi Bolt 기기라서 Unifying 수신기와는 짝이 맞지 않습니다. 장비마다 어느 쪽인지 먼저 확인하세요.
  • 수신기 단자 모양도 확인하세요. 로지텍 데이터시트 기준으로 MX Master 4에는 USB-C 모양 Logi Bolt 수신기가 들어 있습니다. 모니터의 다운스트림 포트는 USB-A이므로, USB-A형 Logi Bolt 수신기나 USB-C → USB-A 변환 젠더가 필요할 수 있습니다.

KVM 사용 시 주의사항

실제로 쓰다 보면 macOS에서 “디스크가 제대로 추출되지 않음” 경고를 만날 수 있습니다.

KVM을 전환하면 모니터 USB 허브가 다른 컴퓨터로 넘어갑니다. 그러면 허브에 꽂아 둔 외장 저장장치도 원래 컴퓨터에서 갑자기 빠진 것과 같은 상태가 됩니다. 삼성 설명서도 USB 관련 설정을 데이터 전송 중에 바꾸면 전송이 취소되거나 데이터가 손상될 수 있다고 경고합니다.

  • 외장 SSD·HDD는 Mac 본체에 직접 연결하는 것을 권장합니다.
  • 모니터 USB 허브에는 키보드, 마우스, 무선 수신기 위주로 연결합니다.
  • 외장 저장장치를 꼭 허브로 공유해야 한다면, KVM을 전환하기 전에 Finder에서 먼저 추출하세요.

정리

  • Mac mini처럼 USB-C로 연결한 컴퓨터는 케이블 하나로 끝납니다.
  • Mac Studio처럼 HDMI/DP로 연결한 컴퓨터는 USB-B 케이블이 하나 더 있어야 키보드·마우스가 따라옵니다.
  • System → USB Source Setup에서 영상 입력과 USB 포트를 짝지어 둡니다.
  • 무선 장치는 블루투스 대신 모니터에 꽂은 USB 수신기로 연결합니다.
  • 저장장치는 허브가 아니라 Mac에 직접 연결합니다.
